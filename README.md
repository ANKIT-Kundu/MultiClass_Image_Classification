# Multiclass Image Classification Web App

This project is a complete machine learning pipeline deployed as a web application that classifies images into multiple categories using a trained model. It combines Python (OpenCV + ML), Flask for the backend, and HTML/CSS/JS for the frontend.

---

## Project Overview

The goal of this project is to explore and demonstrate how machine learning can be integrated into a real-world web application. The model has been trained to classify images of popular sports personalities.

### Example Classes:
- 🏏 Virat Kohli  
- 🎾 Serena Williams  
- ⚽ Lionel Messi  
- 🎾 Maria Sharapova


## 🧰 Tech Stack

### 📚 Machine Learning
- Python
- OpenCV
- Scikit-learn

### 🖥️ Backend
- Flask
- Werkzeug

### 🌐 Frontend
